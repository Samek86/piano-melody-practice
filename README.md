# 피아노 멜로디 연습 (Piano Melody Practice)

## 프로젝트 개요

완전 초보자를 위한 브라우저 기반 피아노 학습 웹앱입니다. 태블릿이나 스마트폰을 실제 피아노 앞에 놓고, 화면에 표시되는 간단한 멜로디(동요 중심)를 따라 연주합니다. 기기의 마이크가 연주한 음을 실시간으로 감지하고, 올바른 음을 칠 때마다 초록색으로 표시하며 다음 음으로 진행됩니다.

### 핵심 특징

- **브라우저 기반**: 앱 설치 없이 바로 사용 (PWA 지원 예정)
- **실시간 음 감지**: Web Audio API + 피치 감지 알고리즘으로 마이크 입력 분석
- **초보자 친화적**: 한 줄 오선지, 멜로디만 표시 (화음 없음, 한 손 연주)
- **즉각적인 피드백**: 올바른 음을 연주하면 초록색으로 표시하고 자동 진행
- **동요 중심 라이브러리**: 친숙한 한국 동요 25-30곡으로 시작

### 대상 사용자

- 피아노를 처음 시작하는 어린이
- 악보 읽기를 배우고 싶은 초보 성인
- 실제 피아노나 키보드를 소유하고 있는 학습자

## 기술 스택 (예정)

- **프론트엔드**: Vite + TypeScript + React
- **오디오 처리**: Web Audio API
- **피치 감지**: PitchFinder (YIN 알고리즘)
- **악보 렌더링**: VexFlow
- **배포**: Vercel/Netlify (HTTPS 필수 - 마이크 접근)
