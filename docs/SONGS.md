## 2. 곡 선정 기준

### 2.1 포함 기준

✅ **친숙도**: 대부분의 한국인이 아는 노래
✅ **단순성**: 초보자가 5-10분 내에 익힐 수 있는 멜로디
✅ **교육적 가치**: 다양한 음정 간격 학습 (2도, 3도, 4도, 5도)
✅ **성취감**: 완주 시 만족감이 큰 곡
✅ **저작권**: 전통 동요 또는 퍼블릭 도메인

### 2.2 제외 기준

❌ 너무 빠른 템포 (180 BPM 이상)
❌ 화음이 필수인 곡
❌ 리듬이 복잡한 곡 (16분음표, 싱코페이션)
❌ 1옥타브 이상 넓은 음역
❌ 저작권이 명확하지 않은 곡

## 3. 데이터 인코딩 방법

### 3.1 수동 입력 (초기)

**도구**: 온라인 MIDI 에디터 또는 MuseScore

**프로세스**:
1. MuseScore에서 악보 입력
2. MIDI 파일로 내보내기
3. Python 스크립트로 MIDI → JSON 변환
4. 수동 검증 및 메타데이터 추가

```python
# tools/midi_to_json.py (예시)
from mido import MidiFile
import json

def midi_to_song_json(midi_path: str) -> dict:
    mid = MidiFile(midi_path)
    notes = []
    
    for track in mid.tracks:
        for msg in track:
            if msg.type == 'note_on' and msg.velocity > 0:
                notes.append({
                    'pitch': msg.note,
                    'duration': msg.time,  # 추가 처리 필요
                })
    
    return {
        'id': '',  # 수동 입력
        'title': '',
        'titleKo': '',
        'notes': notes,
        # ... 나머지 메타데이터
    }
```

## 5. 곡 메타데이터 스키마

```typescript
interface Song {
  // 기본 정보
  id: string;                    // 'twinkle-twinkle'
  title: string;                 // 영문 제목
  titleKo: string;               // 한글 제목
  composer?: string;             // 작곡가
  
  // 음악적 정보
  difficulty: 'beginner' | 'easy' | 'medium';
  tempo: number;                 // BPM
  timeSignature: [number, number]; // [4, 4]
  key: string;                   // 'C', 'G', etc.
  
  // 노트 데이터
  notes: Note[];
  
  // 메타데이터
  tags: string[];                // ['동요', '계절', '동물']
  description?: string;          // 곡 설명
  duration?: number;             // 예상 소요 시간 (초)
  ageRecommendation?: string;    // '4-7세', '전연령'
  
  // 학습 정보
  learningPoints?: string[];     // ['음계 순차 진행', '반복 패턴']
  estimatedPracticeTime?: number; // 분 단위
}

interface Note {
  pitch: number;        // MIDI 노트 번호 (60 = C4)
  duration: number;     // 4 = 4분음표, 2 = 2분음표, 8 = 8분음표
  dotted?: boolean;     // 점음표 여부
  tie?: boolean;        // 이전 음과 연결
  lyric?: string;       // 가사 (선택)
}
```

## 6. 곡 검증 체크리스트

각 곡 입력 후 확인 사항:

- [ ] MIDI 노트 번호가 피아노 범위 내 (21-108)
- [ ] 음역이 1옥타브 이내 (초보자)
- [ ] 템포가 적절 (60-140 BPM)
- [ ] 총 음표 수가 100개 미만 (MVP 단계)
- [ ] 메타데이터 완전성 (제목, 난이도, 태그)
- [ ] 실제 피아노로 연주 가능 확인
- [ ] JSON 문법 오류 없음

## 8. 라이선스 및 저작권

### 8.1 퍼블릭 도메인 확인

대부분의 전통 동요는 퍼블릭 도메인이지만, 특정 편곡이나 가사는 저작권이 있을 수 있음.

**안전한 접근**:
- 100년 이상 된 전통 동요 사용
- 편곡 없이 기본 멜로디만 사용
- 의심스러운 곡은 법률 자문 또는 제외

### 9.2 자동 검증 스크립트

```typescript
// tools/validate-songs.ts
function validateSong(song: Song): ValidationResult {
  const errors: string[] = [];
  
  // 필수 필드 확인
  if (!song.id || !song.titleKo) {
    errors.push('Missing required fields');
  }
  
  // 음역 확인
  const pitches = song.notes.map(n => n.pitch);
  const range = Math.max(...pitches) - Math.min(...pitches);
  if (range > 12) {
    errors.push(`Range too wide: ${range} semitones`);
  }
  
  // 템포 확인
  if (song.tempo < 40 || song.tempo > 200) {
    errors.push(`Unusual tempo: ${song.tempo} BPM`);
  }
  
  return { valid: errors.length === 0, errors };
}
```
